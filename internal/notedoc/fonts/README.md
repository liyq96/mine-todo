# PDF fonts

Noto Sans SC is distributed under the SIL Open Font License in [OFL.txt](OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

`NotoSansSC-Regular.ttf` and `NotoSansSC-Bold.ttf` are static instances of
`NotoSansSC[wght].ttf` at weights 400 and 700, generated with fontTools 4.65.0.
The font license is embedded in the application and included in exported PDF metadata.
PDF embeds only the glyphs used by the exported note; Word uses system fonts.
