# 使用文档

当前发布版本：`v1.0.0`

## 1. 环境准备

建议的本地环境：

- Go `1.22.x`
- Node.js `20.19+` 或 `22.12+`，推荐 Node.js `22`
- Wails CLI

安装 Wails CLI：

```powershell
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

## 2. 首次启动

在项目根目录执行：

```powershell
go mod tidy
cd frontend
npm install
cd ..
wails dev
```

说明：

- `go mod tidy`：同步 Go 依赖
- `npm install`：安装前端依赖
- `wails dev`：启动桌面开发模式

## 3. 主界面使用

### 3.1 新建待办

在左侧顶部输入框中输入标题，按回车即可快速创建待办。

创建完成后：

- 新待办会加入左侧列表
- 右侧自动切换到编辑态

### 3.2 查看详情

点击左侧任意待办，右侧会显示：

- 创建时间
- 标题
- 备注
- Markdown 渲染后的详情内容

### 3.3 编辑待办

右侧点击 `编辑` 后进入编辑态，可以修改：

- 标题
- 备注
- Markdown 详情

编辑采用自动保存，不需要手动点击保存。

### 3.4 完成状态

左侧每条待办前都有圆形勾选控件。

点击后可在：

- 未完成
- 已完成

之间切换。

已完成项会显示更弱的文字层级，并带横向完成标记。

### 3.5 删除待办

右侧点击 `删除` 并确认后，当前待办会从列表移入回收站，右侧详情清空；可通过底部提示立即撤销。

### 3.6 日历看板

左侧快速添加区域下方提供 `日历看板` 入口。

点击后会打开独立弹窗，包含：

- 左侧公历月视图 / 周视图
- 右侧选中日期的待办列表
- 日期角标数量与完成状态提示

交互说明：

- 点击某一天，可查看该日待办
- 点击右侧待办内容，会关闭弹窗并跳转回主界面详情
- 若待办已在左侧列表较深位置，界面会自动滚动到对应条目

### 3.7 搜索、智能视图与标签

- 在应用内按 `Ctrl+K`（macOS 为 `Command+K`）可唤出全局搜索面板
- 全局搜索会检索待办标题、备注、Markdown 正文、标签、子待办，以及笔记标题、正文和标签
- 结果会标明待办或笔记类型，并高亮匹配内容；使用方向键选择、`Enter` 打开、`Esc` 关闭
- 待办筛选位于“目录”标题右侧，笔记筛选位于“笔记”标题右侧
- 智能视图提供全部、今天、未来 7 天、已逾期、无日期、已完成和已归档
- 标签可用于待办和笔记，并能在两种工作区中筛选

### 3.8 优先级与时间

进入待办编辑态后可以设置：

- 点击 `优先级` 按钮，选择紧急且重要、重要不紧急、紧急不重要、不紧急不重要；列表竖线与详情优先级使用一致配色
- 点击目录按钮，下拉选择待办所属目录
- 点击 `时间`，设置待办日期和提醒时间；点击 `确定` 应用，`取消` 不保存本次修改
- 点击圆圈仅切换当前待办的完成状态，不自动新增待办。提醒在应用运行时通过系统通知发送
- 点击 `标签` 后直接输入，回车或移开焦点添加；已有标签显示为标签块，点击右上角叉号移除
- 收藏、归档以及关联笔记；点击 `关联笔记` 后会打开选择弹窗，可搜索并勾选需要关联的笔记

## 4. 笔记工作区

点击左侧顶部的 `笔记` 可切换到独立笔记工作区。

- 点击 `新建笔记` 创建本地笔记
- 左侧按最近更新时间排列全部笔记
- 标题与正文采用自动保存，无需手动提交；保存失败时可点击顶部的“重试”
- 正文支持 Markdown，可在 `编辑` 与 `预览` 间切换
- 输入 `[[笔记标题]]` 可以创建笔记内链，预览态可直接跳转，并显示反向链接；已绑定的目标改名后仍可跳转，同名目标尚未确定时不自动选择其中一篇
- 正文输入时跟随光标滚动，当前输入行保持在可视区域中间附近；字符数量固定在笔记区域右下角
- 可以设置标签、置顶、收藏和归档；点击 `关联待办` 后会打开选择弹窗，可搜索并勾选需要关联的待办
- 右上角删除按钮会在确认后将笔记移入回收站

笔记与待办保存在同一个 `todo.db` 中，切换数据目录时会一并迁移。

## 5. 回收站

侧栏底部的 `回收站` 会集中显示删除的目录、待办和笔记。

- 可以恢复单项内容
- 可以二次确认后永久删除
- 点击 `清空全部` 并再次确认，会物理删除回收站中的全部目录、待办、笔记及相关子项和关联记录，无法恢复
- 删除后的底部提示支持立即撤销
- 未手动处理的内容默认保留 30 天

## 6. 设置弹窗

点击左侧顶部的 `设置` 打开设置弹窗。

当前包含四个 tab：

- `数据`
- `语言`
- `快捷键`
- `关于`

### 6.1 数据

`数据` tab 支持配置本地数据目录。

操作流程：

1. 点击 `选择目录`
2. 使用系统原生目录选择器选中目标文件夹
3. 点击 `保存目录`
4. 在确认层中选择：
   - `迁移现有数据`
   - `打开目标目录`

说明：

- 选择 `迁移现有数据` 时，会先完成保存，生成一致性快照并验证目标库，再切换；目标已有数据库时会提示冲突，不覆盖或静默跳过
- 选择 `打开目标目录` 时，会打开其中的已有数据库；如果没有数据库，会创建一份新的空库
- 目标库或配置提交失败时，继续使用旧配置和旧数据库
- 如果目标目录与当前目录相同，保存按钮会禁用

### 6.2 语言

`语言` tab 当前支持：

- `简体中文`
- `English`

切换后会立即更新界面文案，并写入本地配置文件。

### 6.3 快捷键

`快捷键` tab 以只读方式展示当前支持的键盘操作，包括：

- `Ctrl+K`（macOS 为 `Command+K`）：打开全局搜索
- `↑` / `↓`：在搜索结果中移动
- `Enter`：打开选中的搜索结果
- `Esc`：关闭搜索面板

当前不支持在设置中修改快捷键。

### 6.4 关于

`关于` tab 展示：

- 项目名称
- 当前版本 `1.0.0`
- 发布时间

## 7. 数据与配置文件

默认情况下：

- 配置文件位于用户配置目录下的 `mine-todo/config.json`
- 数据库文件默认位于 `mine-todo/data/todo.db`

配置文件当前包含：

- `storageDir`
- `dbPath`
- `language`

## 8. 打包

在项目根目录执行：

```powershell
wails build
```

Windows 默认输出：

```text
build/bin/Mine Todo.exe
```

## 9. 常见问题

### 9.1 为什么前端单独打开没有数据？

因为页面依赖 Wails 注入的 `window.go.main.App` 绑定，请通过 `wails dev` 或打包后的应用运行。

### 9.2 当前是不是完全离线？

是。当前所有 Todo 数据都保存在本地 SQLite 文件中，不依赖在线接口。

### 9.3 是否还支持富文本编辑？

不支持。当前版本只保留 Markdown 详情编辑与渲染。

### 9.4 是否会自动迁移旧数据库结构？

会。应用启动时会通过增量建表和 `ALTER TABLE ... ADD COLUMN` 补齐当前版本需要的表和字段，不会清空已有待办或笔记数据。

### 9.5 关闭窗口时来得及保存吗？

正常关闭窗口会先等待当前待办、笔记和子项保存完成，再退出。保存失败时窗口保持打开，草稿仍在，可重试后再次关闭。强制结束进程或断电不能依靠正常退出流程保护，仍建议定期备份数据。

### 9.6 恢复目录会恢复哪些待办？

只恢复随该次目录删除一起移入回收站的待办；此前单独删除的待办保持删除状态。旧版本没有记录删除来源的历史待办，可在回收站中逐项恢复。
