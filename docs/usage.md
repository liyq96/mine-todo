# 使用文档

当前发布版本：`v1.0.0`

## 1. 环境准备

建议的本地环境：

- Go `1.22.x`
- Node.js `20+`
- Wails CLI

安装 Wails CLI：

```powershell
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

## 2. 首次启动

在项目根目录执行：

```powershell
go mod tidy
cd frontend
npm install
cd ..
wails dev
```

说明：

- `go mod tidy`：同步 Go 依赖
- `npm install`：安装前端依赖
- `wails dev`：启动桌面开发模式

## 3. 主界面使用

### 3.1 新建待办

在左侧顶部输入框中输入标题，按回车即可快速创建待办。

创建完成后：

- 新待办会加入左侧列表
- 右侧自动切换到编辑态

### 3.2 查看详情

点击左侧任意待办，右侧会显示：

- 创建时间
- 标题
- 备注
- Markdown 渲染后的详情内容

### 3.3 编辑待办

右侧点击 `编辑` 后进入编辑态，可以修改：

- 标题
- 备注
- Markdown 详情

编辑采用自动保存，不需要手动点击保存。

### 3.4 完成状态

左侧每条待办前都有圆形勾选控件。

点击后可在：

- 未完成
- 已完成

之间切换。

已完成项会显示更弱的文字层级，并带横向完成标记。

### 3.5 删除待办

右侧点击 `删除` 可移除当前待办。

### 3.6 日历看板

左侧快速添加区域下方提供 `日历看板` 入口。

点击后会打开独立弹窗，包含：

- 左侧公历月视图 / 周视图
- 右侧选中日期的待办列表
- 日期角标数量与完成状态提示

交互说明：

- 点击某一天，可查看该日待办
- 点击右侧待办内容，会关闭弹窗并跳转回主界面详情
- 若待办已在左侧列表较深位置，界面会自动滚动到对应条目

## 4. 设置弹窗

点击左侧顶部的 `设置` 打开设置弹窗。

当前包含三个 tab：

- `数据`
- `语言`
- `关于`

### 4.1 数据

`数据` tab 支持配置本地数据目录。

操作流程：

1. 点击 `选择目录`
2. 使用系统原生目录选择器选中目标文件夹
3. 点击 `保存目录`
4. 在确认层中选择：
   - `迁移旧数据`
   - `使用空数据`

说明：

- 选择 `迁移旧数据` 时，会将当前 `todo.db` 复制到新目录后再切换
- 选择 `使用空数据` 时，会直接连接新目录；如果没有数据库，会创建一份新的空库
- 如果目标目录与当前目录相同，保存按钮会禁用

### 4.2 语言

`语言` tab 当前支持：

- `简体中文`
- `English`

切换后会立即更新界面文案，并写入本地配置文件。

### 4.3 关于

`关于` tab 展示：

- 项目名称
- 当前版本 `1.0.0`
- 发布时间

## 5. 数据与配置文件

默认情况下：

- 配置文件位于用户配置目录下的 `mine-todo/config.json`
- 数据库文件默认位于 `mine-todo/data/todo.db`

配置文件当前包含：

- `storageDir`
- `dbPath`
- `language`

## 6. 打包

在项目根目录执行：

```powershell
wails build
```

Windows 默认输出：

```text
build/bin/mine-todo.exe
```

## 7. 常见问题

### 7.1 为什么前端单独打开没有数据？

因为页面依赖 Wails 注入的 `window.go.main.App` 绑定，请通过 `wails dev` 或打包后的应用运行。

### 7.2 当前是不是完全离线？

是。当前所有 Todo 数据都保存在本地 SQLite 文件中，不依赖在线接口。

### 7.3 是否还支持富文本编辑？

不支持。当前版本只保留 Markdown 详情编辑与渲染。

### 7.4 是否会自动迁移旧数据库结构？

不会。当前版本不做运行时旧库结构迁移；如果旧库需要清理，请手动处理数据库。
